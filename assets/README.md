# 이미지 에셋 넣는 곳

아래 파일명으로 PNG 이미지를 이 폴더에 넣으면 게임에 자동 적용됩니다.
(파일이 없으면 게임에 내장된 픽셀 플레이스홀더가 사용됩니다)

| 파일명 | 용도 | 권장 크기 |
|---|---|---|
| `koai.png` | 코아이 캐릭터 (달리는 주인공) | 정사각형, 64×64 내외. 배경 투명 |
| `koai2.png` | (선택) 코아이 달리기 2번째 프레임 | koai.png와 같은 크기 |
| `banana.png` | 바나나/컨소시엄 로고 (먹는 아이템) | 정사각형, 32×32 내외. 배경 투명 |
| `obstacle.png` | (선택) 장애물 | 정사각형, 32×32 내외 |

- 픽셀 느낌을 위해 이미지는 작게(저해상도) 만들수록 게임과 잘 어울립니다.
- 배경이 투명한 PNG를 권장합니다.
